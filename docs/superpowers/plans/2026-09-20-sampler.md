# Evaluation dataset sampler implementation plan

> For agentic workers: use the approved design and implement each milestone test-first, with a local commit after each coherent milestone.

**Goal:** Produce deterministic, quota-preserving samples from saved evaluation records without holdout leakage or partial success.

**Spec:** `docs/superpowers/specs/2026-09-20-sampler-design.md`

1. Strict JSON and local-read layer: failing duplicate-key, UTF-8, byte N/N+1, node/depth N/N+1 and symlink confinement tests; implement parser/reader; run focused tests; commit.
2. Dataset/plan validation: correct legal record case first, then invalid records, duplicate candidate/holdout identities, unknown strata, high-risk minimum and contradictory plan tests; implement strict validation; run focused tests; commit.
3. Selection and reporting: failing tests for stable seed, exact quotas, rare high-risk retention, holdout ID/source/digest collision, shortage, incomplete precedence and ordering; implement ranking and house envelope; run focused tests; commit.
4. CLI and release: failing tests for both exit-2 stdout shapes, bounds, read confinement and examples; add CLI, README rule/exit/limits/non-goals, package version/bin/lint/test/check, runnable good and failing examples. Run full check, explicit semantic mutations, source-byte scan, then commit. No central ledger, receipts, remote or network operations.
